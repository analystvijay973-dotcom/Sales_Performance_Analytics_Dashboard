# Sales_Performance_Analytics_Dashboard
Built an interactive Sales Dashboard in Power BI with KPI cards, slicers, and dynamic visualizations.
Analyzed total sales, profit, cost, quantity, and transactions across multiple product categories and brands.
Developed category-wise and brand-wise sales reports to identify top-performing products.
Created map visualizations for state-wise sales analysis and regional business insights.
Used DAX measures and Power Query for data transformation, calculations, and dashboard optimization.
Delivered actionable business insights through interactive charts and performance tracking reports.
